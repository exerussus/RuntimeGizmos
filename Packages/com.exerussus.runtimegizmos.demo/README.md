# Runtime Gizmos — демо

Демо-сцена и чеклист ручной проверки для [Runtime Gizmos](../com.exerussus.runtimegizmos/README.md).

Отдельный пакет, чтобы демо не попадало в релизные проекты и удалялось одним нажатием.

## Установка

**Сначала поставьте основной пакет.** UPM не разрешает git-зависимости транзитивно: демо не может подтянуть плагин за собой, и без него не скомпилируется. По этой же причине зависимость не объявлена в `package.json` — иначе установка падала бы с «Package not found».

```
https://github.com/exerussus/RuntimeGizmos.git?path=/Packages/com.exerussus.runtimegizmos
https://github.com/exerussus/RuntimeGizmos.git?path=/Packages/com.exerussus.runtimegizmos.demo
```

Оба адреса вставляются в Package Manager через **+ → Add package from git URL**, по очереди.

## Использование

1. Пустой объект в сцене → **Add Component → RuntimeGizmos → Demo**.
2. В инспекторе назначить `TestMesh` (любой меш с галкой Read/Write Enabled) и `TestIcon` (любую текстуру) — без них два раздела покажут заглушку.
3. Нажать Play. Разделы переключаются кнопками слева, на что смотреть в каждом — написано прямо на экране.

Компонент помечен `[ExecuteAlways]`, поэтому работает и без Play — это отдельный кейс проверки: в Edit Mode геометрия должна быть видна в Scene View и не мерцать.

## Что внутри

**RuntimeGizmosDemo** — одиннадцать разделов: примитивы, толщина линий, тест глубины, текст, длительность, матрица и Scope, меши и иконки, цвета, паттерны, настройки, нагрузочный тест.

**RuntimeGizmosMigrationDemo** — проверка миграции: одна строка `using Gizmos = RuntimeGizmos.Gizmo;` переводит существующий `OnDrawGizmos` на новую систему без других правок. Второй компонент рядом рисует то же самое из `LateUpdate`, чтобы было видно в игровой камере и в билде.

**[CHECKLIST.md](CHECKLIST.md)** — что проверять руками. Автотесты плагина не могут потрогать HLSL, реальный конвейер URP, тайминги кадра и всё визуальное; чеклист покрывает именно это, по убыванию риска.

## Удаление

Package Manager → пакет → Remove. Следов в проекте не остаётся.
